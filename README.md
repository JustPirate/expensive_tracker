# Expense Tracker — Flutter

A Flutter expense-tracking application built to practice mobile application development, structured UI, and managing financial records in an application workflow.

## Overview

Expense Tracker provides a foundation for recording and organizing personal expenses through a Flutter mobile interface. The project is part of a collection of practical applications used to develop stronger software-engineering and Flutter skills.

## Features

- Expense-focused mobile interface
- Expense recording workflow
- Structured Flutter UI
- Foundation for categorizing and reviewing spending

> The README describes the current project at a high level rather than claiming features that are not present in the repository.

## Tech Stack

- **Flutter** — mobile application framework
- **Dart** — programming language

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android device/emulator or another supported Flutter target

### Setup

```bash
git clone https://github.com/JustPirate/expensive_tracker.git
cd expensive_tracker
flutter pub get
flutter run
```
